# FlowMind AI：2-3 分钟产品 Demo 演示脚本

## 演示目标

在 2-3 分钟内说明 FlowMind AI 如何把会议从一次性记录转化为可执行、可检索、可追溯的团队知识资产。

## 演示前准备

1. 使用本地或 Preview 环境，绝不使用生产项目或真实用户数据。
2. 配置 `DEMO_FIXTURES_ENABLED=true`、专用 Demo 用户和 Demo 环境变量。
3. 执行：

   ```bash
   npm run demo:fixtures:seed
   npm run demo:fixtures:verify
   ```

4. 以专用 Demo 用户登录，打开“产品规划会议：FlowMind Demo 范围”。
5. 准备两个状态：有已索引 fixture 的来源展示，以及无知识库/检索失败的 fallback 展示。

> Mock embedding 只用于可重复的 Demo；不要将它表述为生产语义 RAG。

## 讲解脚本

### 0:00-0:20：问题与定位

**画面**：Landing Page 首屏。

**讲解**：

“很多团队会记录会议，但会议结束后，结论、责任和风险仍然散落在录音、文档和成员记忆中。FlowMind AI 的定位是让会议从记录工具变成可以持续利用的知识资产。”

“这里的体验从产品价值开始，再进入 AI workflow、实际会议案例、Copilot 和来源引用。”

**操作**：点击“查看 Demo”。

### 0:20-0:55：会议智能分析

**画面**：Demo 会议或会议详情中的 Meeting Intelligence。

**讲解**：

“会议录音经过转录后，系统通过异步处理生成结构化结果。这里不是一段不可控的模型长文本，而是摘要、关键决策、行动项和风险。”

“产品负责人可以立即看到范围已经冻结、登录体验是首要改进项，并把后续任务交给相应角色跟进。”

**操作**：依次指出摘要、决策、行动项和风险区域。

### 0:55-1:35：Copilot 与历史知识

**画面**：Meeting Copilot。

**讲解**：

“当前会议信息解决了会后执行问题，但项目成员还会问：之前有没有讨论过上线风险？”

“我向 Copilot 提问：‘之前会议讨论过哪些上线风险？’。系统先保留当前会议上下文，再检索同一用户范围内的历史会议 chunks，最后由 Provider 基于这些上下文回答。”

**操作**：发送问题，展示回答。

### 1:35-2:00：来源引用与安全边界

**画面**：当前响应的来源引用。

**讲解**：

“回答下面展示的是本次请求实际返回的来源会议、日期和片段，而不是模型编造的引用。来源仅在当前响应中存在，不会写入历史消息，也不展示 embedding、similarity、完整转录或 Provider 原始信息。”

“检索 RPC 和数据表都使用 owner-scoped RLS，因此用户无法检索或读取其他用户的会议内容。”

**操作**：打开来源引用，点出“风险讨论会议”“技术评审会议”“项目周会”。

### 2:00-2:25：知识库不可用的诚实回退

**画面**：知识库不可用状态。

**讲解**：

“AI 产品需要在失败时同样可信。当没有索引或检索失败，FlowMind 不会生成空引用或伪造 similarity，而是明确提示知识库不可用，并继续只基于当前会议上下文回答。”

**操作**：切换/展示 fallback 状态，确认没有来源列表。

### 2:25-2:50：工程与运营闭环

**画面**：产品架构说明或 README 的架构图。

**讲解**：

“底层从录音、转录、会议智能分析，到知识 chunks、embedding 和 pgvector 检索，都是独立的 worker 生命周期。AI 调用还进入只读可靠性分析，按 provider、模型、操作、成功率和延迟观察表现。”

“这让产品不仅能演示 AI 能力，也具备权限隔离、失败安全和后续质量优化的基础。”

## 结束语

“FlowMind AI 把一次会议的讨论沉淀为下一步行动和可追溯知识。下一步会在真实、兼容 1536 维的 embedding provider 配置完成后，用离线评估与线上指标验证生产 RAG 质量。”

## 演示验收清单

- [ ] fixture `seed` 和 `verify` 成功。
- [ ] 展示了会议摘要、决策、行动项和风险。
- [ ] Copilot 当前响应显示来源引用。
- [ ] 来源只包含会议名称、日期与片段，不包含相似度或敏感数据。
- [ ] 知识库不可用状态不展示伪造来源。
- [ ] 可以说明 owner isolation、server-only API Key 与 Mock embedding Demo 边界。
